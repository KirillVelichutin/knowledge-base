# Журнал изменений базы знаний

## Назначение

Журнал содержит историю значимых содержательных изменений личной базы знаний.

Он позволяет установить, какие сведения были добавлены, актуализированы или исправлены, какие документы были затронуты и на основании каких источников выполнялись изменения.

Журнал не дублирует историю Git и не предназначен для фиксации каждого действия ИИ-агента.

## Правила ведения

1. Записи добавляются только после фактически выполненных изменений базы знаний.
2. Новые записи размещаются сверху, в обратном хронологическом порядке.
3. Одна логически завершённая операция обновления отражается одной записью, даже если затронуто несколько документов.
4. Каждая запись содержит дату, изменённые документы, суть изменений, основания и нерешённые вопросы, если они есть.
5. Записи должны быть конкретными, краткими и проверяемыми.
6. Исторические записи сохраняются. Последующие изменения отражаются новыми записями, а не переписыванием истории.
7. Агент обновляет журнал автоматически только в рамках явно разрешённой владельцем операции изменения базы.
8. Чтение, поиск, анализ и консультации без изменения файлов не фиксируются.
9. Изменения, выполненные владельцем самостоятельно, могут быть внесены в журнал по его отдельной команде.
