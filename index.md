# My Work Knowledge Base

Личная база знаний для накопления, систематизации и повторного использования информации, полученной в процессе разработки IT-продуктов, обучения и профессиональной деятельности.

База предназначена для быстрого восстановления контекста проектов, поиска проверяемых знаний, сохранения истории значимых решений и обеспечения ИИ-агентов необходимой информацией независимо от истории предыдущих диалогов.

## 1. Основные документы

- [AGENTS.md](AGENTS.md) — обязательные правила работы ИИ-агентов с базой знаний.
- [log.md](log.md) — журнал значимых изменений базы знаний.

**Порядок работы агента:** сначала изучить `AGENTS.md`, затем настоящую карту базы. Остальные документы читать выборочно, исходя из задачи.

## 4. Маршруты поиска информации

| Задача | С чего начать |
|---|---|
| Восстановить контекст проекта | Хаб проекта и указанные в нём источники |
| Изучить архитектуру проекта | Техническая документация и исходный код по ссылкам из хаба, если они доступны |
| Понять назначение продукта или функции | Описание в хабе и указанные продуктовые источники |
| Найти знания по технологии или методу | Раздел `wiki/` по теме. Пока он пуст, используйте связанные первоисточники из `raw/` |
| Обработать учебные или проектные материалы | Указанный источник из `raw/`, затем связанные страницы `wiki/` или `projects/` |
| Проверить историю решений | Источники решений по ссылкам из хаба. Если записи нет, уточните решение у владельца |
| Найти инструкцию специализированной роли | Соответствующий файл в `roles/` |
| Проверить историю изменений базы | Корневой `log.md` |

Маршруты являются отправными точками поиска. Агент может обращаться к дополнительным документам, если это необходимо для выполнения задачи.

## 5. Актуальность навигации

**Последняя проверка карты:** 15.11.2026

Этот файл отражает структуру базы знаний на момент последнего согласованного обновления.

Карта не гарантирует актуальность содержимого каждого связанного документа.

При разрешённых изменениях базы агент может автоматически обновлять навигационные ссылки и корневой журнал изменений в соответствии с `AGENTS.md`.

Если файл, каталог или ссылка отсутствуют, агент должен сообщить об этом. Нельзя придумывать содержимое недоступных материалов.
